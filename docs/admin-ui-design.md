# PawHome Admin Preview — UI Design

## หลักการ
- **เป็นส่วนหนึ่งของ PawHome** ใช้โทเคนเดิมจาก `frontend/src/index.css`: ครีม `#eee8df`, กรมท่า `#2b4486` / `#1d2e5c` / `#e3e9f6`, ทราย `#e4dbcf`, เส้น `#e6ded3`, ตัวอักษร `#1f2433` / `#5e6472`, แดง `#b42318` · ฟอนต์ IBM Plex Sans Thai + Prompt · โลโก้รอยเท้า
- ไม่มีธีมมืด นีออน gradient แรง glassmorphism เงาหนัก หรือ UI library
- **Action first**: สิ่งที่ผู้ดูแลต้องทำอยู่บนสุด กราฟอยู่ล่าง
- สถานะทุกอย่างมีข้อความ ไม่ใช้สีอย่างเดียว

## Layout
- Desktop (≥1024px): sidebar ขาว 16rem (โลโก้ · 3 กลุ่มเมนู · ตัวนับ "รอตรวจ" / "ต้องติดตาม" · กลับเว็บไซต์) + header ขาว sticky (breadcrumb · ช่องค้นหา · avatar + ชื่อผู้ดูแล (พรีวิว))
- Mobile: header มีปุ่มเมนู → drawer (native dialog) · การ์ดเรียงแถวเดียว · KPI 2 คอลัมน์ · ตาราง scroll ภายในกรอบ
- ป้าย "โหมดตัวอย่าง" ทุกหน้า เพื่อไม่ให้เข้าใจว่าเป็นข้อมูลจริง

## องค์ประกอบ (`frontend/src/admin/ui.tsx` + `admin.css`)
`PageHeader` · `Card` (`focus` = กรอบเน้นของคิวติดตาม) · `StatCard` (ไอคอนในวงกลม navy-soft) · `Badge` (neutral/navy/solid/warning/danger/success) · `CaseRow` (รูป · ชื่อน้อง · เจ้าของ/ผู้ขอ · ป้ายเร่งด่วน + ขั้นตอน + เวลาเงียบ · เหตุผล → สิ่งที่ควรทำ · ลูกศร) · `DataTable` · `Field` / `SearchInput` / `Select` / `Chips` · `usePaged` · `Empty` · `Thumb` · Toast (ใช้ `Toaster` เดิม) · `Dialog` / `ConfirmDialog` (ใช้ร่วมกับเว็บหลัก)

## KPI
เรียงตามความสำคัญและมีสีขอบบน: เกินเวลาตาม Policy (แดง) → รอเจ้าของตอบกลับ (เหลือง) → รอส่งมอบ/รอยืนยัน (กรมท่า) → รับเลี้ยงสำเร็จ (เขียว) · แถวที่สองขึ้นต้นด้วยโพสต์ที่ต้องตรวจสอบ (เหลือง)

## ผลการตรวจโพสต์
โพสต์ที่ยังไม่แสดง: ✓ อนุมัติ (เขียว) · ↩ ส่งกลับไปแก้ไข (เหลือง) — ต้องใส่เหตุผล (มีเหตุผลสำเร็จรูป) เหตุผลแสดงในโพสต์และบันทึกในประวัติกิจกรรม

## ป้ายความเร่งด่วน
| ระดับ | ป้าย | เงื่อนไข |
| --- | --- | --- |
| urgent | `!! ด่วน` (แดง) | เจ้าของเงียบ ≥ 72 ชม. · ส่งต่อเร่งด่วน · ข้อพิพาท |
| high | `! ต้องติดตาม` (เหลือง) | เงียบ ≥ 48 ชม. หรือ Admin ตั้งธง |
| reminder | `เฝ้าดู` (น้ำเงินอ่อน) | เงียบ ≥ 24 ชม. |
| normal | `ปกติ` | — |

เคสข้อพิพาทมีแถบแดงด้านซ้ายในรายการ

## หน้า
ภาพรวม · จัดการสัตว์เลี้ยง · คำขอรับเลี้ยง (+ รายละเอียดเคส 5 ขั้น 4 แท็บ) · ผู้ใช้งาน · ประชาสัมพันธ์ · รายงาน · ตั้งค่า

## Pet Detail (เว็บหลัก)
จังหวัดเป็นป้ายกรมท่าพร้อมไอคอนหมุด แยกจากชนิด/สายพันธุ์ · ชื่อยาวตัดบรรทัดได้ · การ์ดข้อมูลเพิ่ม "สถานะการรับเลี้ยง" · ไม่มีรูปแสดง "ยังไม่มีรูปภาพ" · คำอธิบายว่างแสดงข้อความแทน · ลบ/อนุมัติ/ไม่ผ่าน/ยกเลิก ใช้ ConfirmDialog
